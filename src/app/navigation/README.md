# src/app/navigation

Configuração de navegação do app (navigators, rotas raiz, linking).

- **Pode ficar aqui:** navigators raiz e a composição das telas expostas pelo `index.ts` de cada feature.
- **Não pode ficar aqui:** telas, regras de negócio ou componentes de uma feature (eles ficam em `src/features/<nome>/`).
- Nenhuma biblioteca de navegação está instalada ainda. A escolha exige justificativa no `plan.md` da spec que a introduzir e um ADR em `docs/adr/`.

Veja [docs/estrutura-de-pastas.md](../../../docs/estrutura-de-pastas.md).
