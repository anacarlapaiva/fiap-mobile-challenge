# src/assets

Arquivos estáticos: fontes, imagens e ícones.

- **Pode ficar aqui:** arquivos binários e SVGs organizados em subpastas (`fonts/`, `images/`, `icons/`).
- **Não pode ficar aqui:** código TypeScript com lógica. `assets` não importa nenhuma outra camada.
- Fontes nativas exigem configuração em `android/` e `ios/`, que só pode ser alterada com pedido explícito.
