# src/shared/hooks

Hooks React genéricos, reutilizáveis por qualquer feature (ex.: `useDebounce`, `useAppState`).

- **Pode ficar aqui:** hooks sem conhecimento de domínio, nomeados `useAlgo.ts`, com o teste ao lado.
- **Não pode ficar aqui:** hooks de uma única feature (ficam em `src/features/<nome>/hooks/`).
