# src/shared/lib

Utilitários e integrações de infraestrutura agnósticas de domínio (formatação, datas, cliente HTTP base, wrappers de bibliotecas).

- **Pode ficar aqui:** funções puras e adaptadores de bibliotecas de terceiros, com testes ao lado.
- **Não pode ficar aqui:** chamadas a endpoints de uma feature específica (ficam em `src/features/<nome>/api/`).
