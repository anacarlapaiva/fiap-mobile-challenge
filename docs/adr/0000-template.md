# NNNN. Título da decisão no imperativo

- **Status:** Proposto | Aceito | Substituído por NNNN (link para o ADR novo) | Descontinuado
- **Data:** AAAA-MM-DD
- **Decisores:** nomes ou papéis

## Contexto

Qual problema ou força motivou a decisão? Quais restrições técnicas, de negócio ou de equipe existem? Descreva fatos, não a solução.

## Decisão

O que foi decidido, de forma direta e verificável. Ex.: "Usaremos X para Y, configurado em Z."
