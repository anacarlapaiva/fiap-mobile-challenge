# Specs

Contrato de produto: o quê, critérios de aceite e fora do escopo. Cada pasta `NNN-nome/` tem só `spec.md`. Plano e tarefas existiram durante a implementação e foram apagados ao concluir.

A lista completa está em [docs/README.md](../README.md#produto-specs). O ciclo de uma spec nova está em [fluxo-sdd.md](../fluxo-sdd.md).
